# mygithubproject-
Простий Калькулятор на Python
Це невеликий навчальний проєкт, розроблений для демонстрації базових операцій Git, GitHub та принципів розробки (створення функцій, обробка винятків та юніт-тестування).

Проєкт містить функції для чотирьох основних арифметичних операцій.

🚀 Функціонал
Проєкт реалізує наступні функції у файлі main.py:

Додавання (add_numbers)

Віднімання (subtract_numbers)

Множення (multiply_numbers)

Ділення (divide_numbers) з обробкою помилки ділення на нуль.

Для забезпечення якості коду, реалізовані юніт-тести у файлі test_main.py.

🛠️ Як запустити проєкт
1. Клонування репозиторію
Спочатку склонуйте репозиторій на свій локальний комп'ютер:

git clone [https://github.com/OlPlaksa/mygithubproject-.git](https://github.com/OlPlaksa/mygithubproject-.git)
cd mygithubproject-

2. Запуск програми
Виконайте головний файл main.py за допомогою інтерпретатора Python:

python main.py

Вивід програми продемонструє результати всіх чотирьох операцій калькулятора, включно з прикладом обробки помилки ділення на нуль.

3. Запуск тестів
Щоб переконатися, що весь функціонал працює коректно, запустіть юніт-тести:

python test_main.py

Успішний результат покаже, що всі тести пройшли (наприклад, Ran 5 tests in 0.001s OK).
